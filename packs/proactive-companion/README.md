# proactive-companion (贴心陪伴与主动关怀扩展包)

专为 `dsh-qqbot` 打造的主动陪伴扩展包。解决机器人“你不找她她就不找你”的冷清感，让机器人在 QQ 私聊中具备适时主动关怀主人、日常冒泡分享的陪伴感。

---

## ✨ 核心特性（双路线并行架构）

### ⏰ 路线一：作息时段定时关怀 (Window Greeting)
针对关键生活与工作节奏，在特定时间段内主动发起自然问候（每个窗口当天最多触发 1 次，防止重复刷屏）：
- **早安问候**：默认 `08:30` ~ `09:30`，元气问候开启新的一天；
- **午后提神**：默认 `14:00` ~ `14:30`，午后易困时段提醒伸伸懒腰、喝口温水；
- **傍晚提醒**：默认 `18:30` ~ `19:30`，傍晚下班/放学时段关心辛苦、提醒吃好吃的；
- **晚安陪伴**：默认 `22:30` ~ `23:30`，深夜临睡提醒早点休息、祝好梦。
*注：各时段支持在 Web 设置页独立开启/关闭，并可灵活自定义具体起止时间点。*

### 💬 路线二：空闲超时主动冒泡 (Idle Poke)
- **超时触发**：当主人连续较长一段时间未在私聊发消息（**默认阈值调整为 3 小时**），且当前处于活跃时段时，机器人会主动戳一戳主人或分享日常。
- **独立开关**：支持在 Web 界面和指令中单独开启或关闭该机制，并可自由设定空闲超时小时数。

### 🛡️ 频控与多层防骚扰退避（绝不成为垃圾消息）
1. **夜间绝对免打扰 (DND)**：默认 `23:30` ~ 次日 `08:30` 静默，不主动发送任何非紧急打扰消息。
2. **每日上限硬闸门**：每天最多主动关怀 `4` 次（可配置）。
3. **最小发送冷却**：两次主动发送之间至少间隔 `2.5` 小时。
4. **智能指数退避与休眠**：
   - 若主动发了 1 次主人未回，下次触发冷却时间自动翻倍；
   - **连续 2 次无应答即进入休眠**，不再继续打扰，直到主人下次主动说话才重新激活。
5. **对话免打扰保护**：
   - 若主人在最近 20 分钟内才刚在说话，定时时段问候会自动避让，不生硬打断当前正在进行的对话。

## ⚙️ 配置与使用方式

### 1. Web 界面设置（最直观）
在 DSH 桌面端进入 **QQ 机器人扩展设置**（设置中心），找到 `companion-daemon`，支持图形化表单配置：
- **全局控制**：
  - `启用主动关怀总开关` (bool)
  - `主人 OpenID` (string)
  - `每天最大关怀次数` (number，默认 4)
  - `两次关怀最小间隔(小时)` (number，默认 2.5)
  - `免打扰开始/结束时间` (string，默认 23:30 ~ 08:30)
- **【路线一】作息时段关怀**：
  - `开启作息时段关怀` (bool，总开关)
  - `早安问候` 开关及起止时间（默认开启，08:30 ~ 09:30）
  - `午后提神` 开关及起止时间（默认开启，14:00 ~ 14:30）
  - `傍晚提醒` 开关及起止时间（默认开启，18:30 ~ 19:30）
  - `晚安陪伴` 开关及起止时间（默认开启，22:30 ~ 23:30）
- **【路线二】空闲超时冒泡**：
  - `开启空闲超时主动冒泡` (bool，总开关)
  - `空闲超时阈值(小时)` (number，默认 3 小时)

### 2. QQ 内斜杠命令
在 QQ 私聊或群聊中发送：
- `/companion` 或 `/companion status`：查看完整的双路线运行面板、各时段今日问候状态、当前已空闲时长与频控统计。
- `/companion on` / `/companion off`：开启或暂停总开关。
- `/companion test`：立即演练一次关怀问候（用于测试通道或查看效果）。
- `/companion set idle 3`：将空闲超时阈值改为 3 小时（或其他数值）。
- `/companion set window on/off`：单独开启/关闭时段关怀路线。
- `/companion set poke on/off`：单独开启/关闭空闲超时冒泡路线。
- `/companion set max 4`：设置每天最多关怀次数。
- `/companion set dnd 23:30 08:30`：修改夜间免打扰时段。

### 3. 自然语言与 LLM 工具 (companion_manage)
聊天过程中，你可以随时用口语告诉机器人：
- *“下午我要专注备考，今天别主动找我了”*
- *“把空闲冒泡时间改成两小时”*
机器人可自动识别并调用 `companion_manage` 工具修改策略。

## 📝 版本更新历史 (Changelog)

### v1.0.2 (2026-10-24)
- **时段关怀默认开关优化**：路线一中默认仅开启【早安问候 (08:30~09:30)】与【晚安陪伴 (22:30~23:30)】，将【午后提神】与【傍晚提醒】设为默认关闭（可按需在设置中随时勾选）。
- **双路线配额合理化调整**：
  - 明确每日最大关怀次数（`dailyMax`）为路线一（时段问候）与路线二（空闲超时冒泡）**共享的全局总额度**；
  - 默认单日总上限从 4 次调整为 **5 次**。早晚时段问候各占 1 次，白天为路线二空闲冒泡保留了足额的 3 次主动搭话机会（且符合 QQ 开放平台单日主动消息合规限额），杜绝时段问候过早占满额度导致晚安或白天空闲无法冒泡的问题。

### v1.0.1 (2026-10-24)
- **底层直发通道升级**：适配 QQ 开放平台官方 REST 接口（`/v2/users/{openid}/messages`），自带 AccessToken 鉴权与刷新机制，确保机器人即使在冷启动或无活动会话时也能稳定向私聊推送关怀。
- **目标 OpenID 智能推断**：优先读取设置面板配置，未配置时自动跟随插件配置的第一主人，免除繁琐手填。
- **官方市场规范对齐**：作者署名统一为 `TGSWYH`，完善配套封面美术资源与中文文档。

## 🚀 生效方法

扩展包源码位于 `D:\dsh workspace\dshqqbot\extension-packs\proactive-companion`。
在 DSH 桌面端中，**重启一次 QQ 机器人插件**（或重新保存一次配置），即可自动加载最新双驱动并行关怀机制！
